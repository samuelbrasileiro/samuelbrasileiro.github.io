# Samuel Brasileiro — Academic Website

A lightweight, accessible, English-language academic portfolio for Samuel Brasileiro dos Santos Neto.

## Structure

- `index.html` — content, semantic markup, publication links and metadata
- `styles.css` — responsive layout and typography
- `script.js` — small optional current-year enhancement
- `assets/portrait.jpg` — photograph provided by Samuel
- `assets/favicon.svg` — favicon
- `.nojekyll` — avoids Jekyll processing on GitHub Pages

The site does not require a build step or an npm install.

## Deploy to GitHub Pages

1. Create the public repository `samuelbrasileiro.github.io` in the `samuelbrasileiro` account.
2. Upload the **contents** of this folder to the root of its `main` branch.
3. In repository Settings → Pages, choose **Deploy from a branch** → `main` → `/(root)`.
4. The site will then be available at `https://samuelbrasileiro.github.io/` when GitHub Pages has finished deploying.

For local preview, open `index.html` in a web browser or run `python3 -m http.server 8000` within this directory.

## Visual references

The redesign favors scannable research content and directly linked evidence rather than promotional hero illustrations, drawing structural lessons from:

- [Amy J. Ko](https://faculty.washington.edu/ajko/) — topical research and clear publication access
- [Ethan Fast](https://www.ethanfast.com/) — succinct bio and dated work entries
- [Andrej Karpathy](https://karpathy.ai/) — minimalist static site with clear sections

These are organizational references, not templates or copied layouts.
